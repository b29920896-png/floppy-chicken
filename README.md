# floppy-chicken
A Flappy Bird clone built with Python and Pygame, made for beginners to play and learn from.
Enter a unique player name, pick your bird's color, and flap through the pipes to climb the leaderboard.
Collect power-ups in the pipe gaps: Shield for temporary immunity, Slow-Mo, and 2x Points.
Scores are saved locally in a JSON file, so you can come back and beat your personal best.
Easy to customize: tweak gravity, pipe gap, colors, and power-ups at the top of the code.
